# Passenger Counter App

A simple web app that lets you track the number of passengers or entries in real time. It includes an increment button, a save button, and a history of previous counts.

## Features

- Increment the current count with a single click
- Reset the counter after saving the current value
- Display a running history of saved entries
- Clean, responsive layout with a polished UI
- Built using plain HTML, CSS, and JavaScript

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/karanjthakur/Passenger-Counter-App.git
```

2. Open the project folder:

```bash
cd Passenger-Counter-App
```

3. Open `index.html` in your browser.

Alternatively, you can run a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## App Behavior

- Click `INCREMENT` to increase the count.
- Click `SAVE` to record the current total in the previous entries section.
- The counter resets after saving so you can start a new count.
